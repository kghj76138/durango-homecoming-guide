    제작·가공

    제작·가공·개조·수리의 규칙과 공식입니다. 표의 숫자는 배포된 게임의 규칙 함수(CraftMathRules 등)를 직접 실행해 얻은 값입니다. 제작법 720개의 재료·작업대·시간은 제작법 전체 목록에 있습니다.

    #개요

    제작 창에서 하는 일은 셋입니다.

    • 제작(type 0, 625개) — 재료를 넣어 새 물건을 만든다. 성공 뒤 한 번 더 굴려 대성공을 가른다.
    • 가공(type 1, 73개) — 무두질·금속 처리·다듬기·말리기·발효처럼 재료 자체를 바꾼다. 가공 가능 횟수를 하나 쓴다. 대부분 작업대에 맡긴다.
    • 개조(type 2, 22개) — 옷·장갑·신발 등에 개조 칸 꼬리표를 쓴다. 능력치 곡선을 쓰지 않고 고정 확률이다.

    한 번의 제작은 이렇게 흐릅니다: 재료·작업대·도구 확인 → 결과 레벨 결정 → 결과 레벨로 요구치 계산 → 내 제작 능력과 비교해 성공률·대성공률 → 에너지·피로 소모 → 작업 시간 → 결과 굴림 → 경험치.

    #제작 능력

    제작 성공률을 가르는 것은 요구 능력치(무기 제작·옷 제작·요리·가구·건설·재봉·금속 가공·공예)입니다. 복원판의 제작 능력 기저값은 다음 식입니다. 포크

    제작 능력 = 35 + floor((관련 기본 능력치 + 2 × 캐릭터 레벨) / 6) + 장비·칭호·음식 보너스

    포크의 기본 능력치는 레벨과 같게 커서(60레벨 = 60) 원작 척도(60레벨 맨몸 65)에 맞추려고 2×레벨을 더합니다. 농사와 채집 넷(식물 채집·채광·도축·분해)은 이 식을 쓰지 않고 관련 기본치 평균 그대로입니다. 기본 능력치가 무엇에서 오는지는 캐릭터 능력치에 있습니다.

    게임 규칙 함수 CraftMathRules.CraftingAbility 를 직접 실행한 값

    #성공률과 실패

    요구치 d 는 제작법의 required_ability_value 식에 결과 레벨을 넣은 값입니다(예: 0.5 * level — 레벨 40 이면 20). 능력치 a 가 d 이상이면 반드시 성공하고, 모자라면 제곱으로 떨어집니다. 원작

    성공률 = clamp(1 − (max(0, d − a) / 100)², 0, 1)

    실패하면 재료마다 따로 손실 굴림을 합니다(손실 확률 = 부족분/100 원작, 재료마다 개별 판정은 추정). 성공·대성공이면 재료를 모두 씁니다.

    #대성공

    대성공은 성공한 제작 중에서 한 번 더 굴립니다(직접 제작). 가공·위탁 제작은 한 번 굴려 대성공/성공/실패를 한꺼번에 가릅니다. 원작

    #결과 레벨

    결과 레벨은 재료 레벨의 평균(버림)을 기술 레벨과 작업대 레벨 중 낮은 쪽으로 누르고, 제작법의 최소~최대 레벨로 묶습니다. 포크

    레벨 = clamp(min(floor(재료 레벨 합 / 재료 수), 상한), 제작법 min_level, 제작법 max_level) 상한 = min(그 제작법 기술 범주 레벨, 작업대 레벨) (0 = 모름 → 빼고 고른다)

    섬마다 자동으로 서는 간이 작업대는 레벨 상한이 없습니다(손제작처럼 기술만 봄). 제작법 범위가 마지막에 걸리므로 기술이 낮아도 min_level 짜리는 나옵니다.

    #작업량·에너지·피로·경험치

    제작 한 번의 작업량 e는 제작법에 적힌 effort 값이고, 비어 있으면 레벨 식을 씁니다. e 가 에너지·피로·(기본) 작업 시간을 정합니다. 원작

    기본 작업량 e = 5 + (레벨 − 1) × 0.5 에너지 = e × 0.7 × (1 + 에너지 소모 증폭) × 섬 배수 피로 = 2 × √e × 섬 배수 제작 경험치 = max(2, 4 + 결과 레벨)

    작업량·경험치는 CraftEffort·CraftExp 실행값, 에너지·피로는 그 e 로 계산 (effort 가 적힌 제작법은 그 값이 e)

    #작업 시간

    손작업 시간은 제작법의 duration(초)이고, 0 이면 작업량 e 초입니다(맡기는 제작법의 0 은 0초). 여기에 복원판의 작업 시간 배율 ×0.5 를 곱합니다. 사용자 결정

    그 위에 사용자 결정 능력치 여유·안전 섬·희귀 속성 감소가 붙습니다:

    시간 = 기본 × max((1 − 감소 합) × (1 − 0.25 × clamp((능력 − 요구치) / 200, 0, 1)), 0.3) 감소 합 = 개인섬·도시섬 제작 단축(craft_time_reduction_safe) + 작업대 희귀 속성 「더 짧은 시간」 0.05

    캐시 아이템의 고정 시간 보정(bm_fixed_craft_duration)이 있으면 그 초가 상한입니다.

    #가공과 제련

    가공(type 1)은 새 물건 대신 들고 있는 재료를 바꿉니다. 가공 가능 횟수(modifiable_count)가 남아 있어야 하고, deduct_modifiable_count 인 가공은 한 번에 하나를 씁니다. 채집 대성공 재료는 횟수가 +1, 채집 실수 재료는 −1 입니다.

    • 다듬기(trim*) — 나무/돌/뼈에 다듬은 재질 꼬리표를 더한다(원래 꼬리표 유지).
    • 재료 가공(process*) — 다듬은 재질을 가공 재질로 올린다.
    • 말리기·훈연·절이기(dry*/smoke*/salt*) — dried/dried_leather/smoked 를 붙이고 「젖음」을 뗀다.
    • 무두질(tan*) — 건조 꼬리표를 남기고 tan_leather 를 더한다.
    • 잇기(extend_stick/rope/sheet) — 막대·줄·천 크기 사다리를 올린다.
    • 요리 가공(분류 cook) — 날 것 꼬리표(raw_food, wet)를 뗀다.

    #개조

    개조(기술지원, type 2)는 옷·모자·장갑·신발·가방·무기·도구에 개조 칸 하나를 두고 꼬리표를 씁니다. 능력치와 상관없이 고정 확률입니다 — 대성공 5%, 성공 80%, 나머지 실패(큰 실패 없음). 원작

    • 대성공: 모든 꼬리표가 최대 레벨.
    • 성공: 꼬리표마다 최소~최대 사이 두 번 굴려 낮은 쪽 추정 — 낮은 레벨이 흔합니다.
    • 레벨/최대 비율 0.9 초과는 「아주 희귀」, 0.6 초과는 「희귀」 표시.
    • 실패하면 물건은 그대로입니다. 개조 칸은 다시 써서 덮을 수 있습니다.
