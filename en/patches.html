    #Development progress notice

    The following is work in progress. Some of it is not in a public version yet.

    2026.10.01 progress notice

    📋 싱글 ↔ 멀티 통합 개발 진행 안내 — 2026.10.01

    전체 진행은 약 70%로 추정합니다. 지난 안내(09.29, 약 40%) 이후 통합에 필요한 기능 구현을 대부분 마치고 시험 환경 검사를 통과시켰습니다. 작업량을 센 비율이 아니라 남은 조건의 구현·검증 상태를 기준으로 한 추정치입니다. 아래는 개발 중인 내용이며 공개 버전에는 아직 적용되지 않았습니다.

    이번에 구현하고 시험 환경에서 확인한 부분

    • 싱글이 쓰던 규칙과 수치(수리·길들이기·행동 비용·경험치·맛 판정·전투·사망·기후·휴식 효과 등)를 멀티 서버가 같은 코드로 쓰도록 맞췄습니다.
    • 멀티 서버에서 영어로 뜨던 거절·안내 문구 약 400곳을 싱글과 같은 한국어 문구로 바꿨습니다.
    • 멀티 서버에 없던 기능을 옮겼습니다: 안전가옥 이야기 임무, 항구 시작 재료, 시체 상자 한 번에 가져오기, 상점(코스튬·제작법 책·도면), 몸통박치기 넘어뜨리기 등 전투 효과, 포획·물 마시기 시간, 집 안 가구 분위기·세트 효과.
    • 군도·정예 소형섬·온대 불안정섬을 개인마다 따로 열고, 남겨 둔 불안정섬을 이어 갈지 포기할지 묻는 확인창을 붙였습니다.
    • 개인섬에서는 사유지를 선언하기 전에도 싱글처럼 섬 어디에나 건축할 수 있고, 부지 선정 시간도 싱글과 같습니다. 다른 사람의 섬에서는 사유지 권한이 있어야 합니다.
    • 다른 사람 섬을 방문 중일 때 얻은 진행(구매·보상·제작 등)이 상대 서버가 갑자기 꺼져도 사라지지 않도록 저장 순서를 바꿨습니다.
    • 기존 싱글 세이브를 통합 서버로 옮기는 기능과, 통합 서버 진행을 다시 싱글로 가져가는 기능을 타이틀에 연결했습니다. 실제 세이브 복사본으로 옮기기를 시험했고 원본은 그대로 남았습니다.
    • 서버 시험 묶음 180개 중 177개를 통과했고, 남은 3개도 고친 뒤 따로 돌려 통과했습니다.

    완료까지 남은 부분

    • 실제 게임 화면에서 전체 흐름 확인(새 캐릭터 → 안코라 → 개인섬 → 불안정섬 → 다른 사람 섬 방문 → 귀환).
    • 서로 다른 PC 두 대 사이의 방문과, 서버가 갑자기 꺼졌을 때 잃는 진행이 60초 이내인지 실측.
    • 확인을 마친 뒤 세이브 백업·되돌리기 준비와 함께 한 번에 공개 배포.

    현재 공개 게임은 기존 버전을 유지합니다. 통합은 확인을 마친 뒤 한 번에 적용하며, 그 전까지는 이렇게 진행 안내로 따로 알리겠습니다.

    2026.09.29 progress notice

    📋 싱글 ↔ 멀티 통합 개발 중간 안내 — 2026.09.29

    전체 진행은 약 40%로 추정합니다. 작업량을 수치로 집계한 비율이 아니라, 전체 통합에 필요한 조건의 구현·검증 상태를 기준으로 한 추정치입니다. 아래는 개발 중인 내용이며 운영 서버·공개 버전에 아직 적용되지 않았습니다.

    구현하고 시험 환경에서 확인한 부분

    • 캐릭터·인벤토리·개인 섬·동물을 멀티 서버로 가져가는 흐름과 정상 귀환 시 데이터 반영.
    • 데이터 소유 서버의 승인, 중복 처리 방지, 예전 접속 권한 차단 등 저장 데이터 보호.
    • 음식 섭취·소화·이동 취소와 재료 반환, 퀘스트 보상·칭호의 기존 처리 규칙 연결.
    • 건축물 배치·개조·수리·장식·이름 변경·낙서 등 여러 생활 동작을 통합 경로에 연결.
    • 멀티 서버가 한 번 중단된 뒤 싱글로 복구하고, 같은 서버 또는 다른 서버로 다시 이동하는 흐름.

    진행 중인 부분

    • 음악 재생 등 남은 생활 동작, 다른 이용자와 상호작용하는 경로의 통일.
    • 서로 다른 데이터 소유 서버를 사용하는 이용자들의 공동 플레이 검증.
    • 서버 중단이 반복돼도 이전 기록과 최신 데이터를 안전하게 보존하는 복구 처리.

    완료까지 남은 부분

    • 모든 플레이 동작의 싱글·멀티 결과 일치 확인.
    • 실제 서로 다른 PC와 게임 화면에서 이동·협동·귀환 검증.
    • 운영 서버 통합 적용과 런처를 통한 공개 배포.

    현재 공개 게임은 기존 버전을 유지합니다. 개발 중간 진행 안내를 실제 배포 완료 내역과 구분해 계속 알리겠습니다.
