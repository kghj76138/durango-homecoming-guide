    #Sailing and archipelagosLast changed 2026.09.24.5

    Touching the Harbor opens the original sailing window. Each Sea (region template) carries one route per Unstable index, and you choose the index with the dial in the sailing window. If a Sea has several islands with different line-ups, all are listed, labeled with their main species and herd count Estimated.

    Rules

    • Islands below Lv 60 always have Unstable index 1 Changed from original (developer decision) — only the index-1 route is listed, so the dial does not appear. DLL check: Lv 55 island, index 5 requested → 1; Lv 60 island, index 5 → 5, index 10 → 10.
    • The selectable index cap is set by Pioneer rank (original pioneer.region_access, table below) Original (confirmed). The sailing window lists up to 10 tiers.
    • Leaving a Stable island (Tamed Island) is not level-gated. The “island level −4” rule only remains for travel between unstable islands Changed from original (developer decision).
    • Choosing “Give up for a new island” deletes that island's save and rebuilds the archipelago.
    • Archipelago selection: only archipelagos that are active, same biome, same level, without epic/Raid/Season/event in the name, with two or more islands, an index in range, and a Pioneer mission are candidates (elites pass) Original (confirmed).
