    Gathering

    Rules for getting materials from natural resources — rolls, levels, properties, tools and skills, work time, Energy, replenishment and craters. Individual gatherables are listed in Gatherables.

    Source grade — the badge next to a value shows its basis. Last changed next to a section title is the public version in which that section's content last changed, and links to Patch history.

    • Estimated A value the restoration filled in because the original data has no field for it (e.g. rules that were server-only) — 24 on this page
    • Changed from original (developer decision) A value that exists in the original but was set differently by developer decision — 7 on this page

    #Overview UnverifiedLast changed 2026.09.27.6

    Tapping a natural resource (tree, bush, rock, shoal of fish, box, etc.) shows the Yield row (generator) it offers. Each line has a set quantity, required tool and required technique, and loses one per gather. This page covers the rules for rolls, levels, properties, time, cost, replenishment and craters; Gatherables covers each gatherable's yield and where it appears.

    Gatherable type
    248 kinds (630 yield lines, 171 kinds of items obtained)
    Props with unknown yield
    90 kinds — city props and furniture that the original extract filled with four default lines (Metal Stick, Metal Nail, Metal Links, Metal Accessories)
    Gathering table version
    20 (when the build changes, only the natural-resource entries of the saved gathering records are cleared once and re-rolled from the new table)

    Flow of a single gather

    • The first time you touch a natural resource, the yield lines and quantities (random between min and max) of its Type are fixed. Quantities are rolled once per kind and shared by all resources of that kind on the island. Only rare lines (chance below 1) are rolled per individual resource.
    • The order is: tool check → technique check → work time (gauge) → roll (success, flawless, mistake) → item and properties → Energy/Fatigue cost → EXP.
    • When a line's quantity reaches 0, the line disappears; when all lines are gone, the resource disappears too. A tree falls once its log line runs out, and a bush once its root line runs out, even if other lines remain.

    #Rule: Success · Flawless Success · FailureLast changed 2026.09.24.5

    The roll is one integer from 1 to 99. The original constants.item.default_improvement gathering roll is success 0.8 · flawless 0.05 · critical failure 0 (the remaining 0.15 is a mistake). Original (confirmed)

    RollResultRatio
    1–15Failure15%
    16–95Success81%
    96–99Flawless Success4%
    • If the roll is 5 or less, you get nothing even among mistakes (confirmed).
    • Flawless Success: the item's processing count +1, plus one extra good property. Estimated
    • Failure: processing count −1, plus one bad property. Estimated
    • The tool rare effect Meticulous Gatherer (original great_success_plus_collect_on_tool +0.05) lowers the flawless threshold by 5 — a roll of 91 or higher is flawless (about 9%).
    • The tool rare effect Extra Extra (original collect_burst +0.1) gives one extra item with a 10% chance.

    #Properties attached to materialsLast changed 2026.09.24.5

    Material obtained by gathering or butchering (anything but food) can get random properties (latent attributes). Each property's effect is on the Material properties page.

    • Chance a property is attached 30%, Chance two of them are attached at once 5% Estimated
    • A family a material already has a property from is not added again. Soft and hard materials can get different families.
    • Property level is random from 1 up to a cap. Cap = 1 per 20 item levels (max 3) + 1 per 3 unstable-index steps, never above the processing cap 8. Changed from original (developer decision)
    • Logs (by tree kind) and butchering yields (by species) get Fixed property on top of the random properties (Material properties).

    #Required techniquesLast changed 2026.09.27.6

    Original technique rewards (gathering rewards in rewards.txt, type 0) only record a name, and that name is the same text as the gathering line's name. So we find gathering line name → the technique node that rewards that name and allow gathering only once that node is learned. Estimated

    • Matching order: item name → line name (exact · comma-separated parts · ignoring spaces) → when the “… name” tail matches Exactly one node.
    • Nodes costing 0 skill points unlock automatically when you reach their technique category level — early gatherables like branches, pebbles and berries are never locked.
    • Lines no node rewards (fish, cotton, tendon, etc.) are not locked. Gift box contents aren't gathering, so they aren't locked either.
    • As your gathering technique category level rises, the workload per gather drops and work time gets shorter (see below).

    Time formula

    Base = branch base value × (1 + 0.01 × (gatherable level − 1)) × (1.15 for rare lines), capped at 12s on the original scale → × 0.5 Actual = base × max(0.3, (1 − total modifiers) × (1 − 0.2 × technique progress) × (1 − 0.25 × tool progress)) Progress = (level − 1) / 59 (level 1 → 0, level 60 → 1)
    • Technique progress: gathering technique category level. At 60 it is 20% faster.
    • Tool progress: the level at which the tool used carries the required tag (= tool level). At 60 it is 25% faster. Bare hands: 0.
    • Modifier sum: original modifiers from equipment and status effects — gathering_time_reduction “Plant Gathering Time Reduction” (tag level × 0.005, plant branch only), bm_collecting_time_reduction “Gathering Time Reduction” (level × 0.01), collect_time_reduction_safe “Tamed/Civilized Island Gathering Time Reduction”.
    • With a “… fixed time” modifier (bm_fixed_collect_duration etc.), that many seconds is the cap.
    • No matter how much it is reduced, it never goes below 30% of the base.

    #Restocking and regrowthLast changed 2026.09.24.5

    Original player testimony: “Gatherables weren't removed completely; at least 1 gatherable element had to remain for them to replenish. Respawn time varied with the depletion rate.” Changed from original (developer decision)

    • A natural resource that is fully gathered and gone doesn't respawn in place. New resources on an island come only from ecological spreading, craters, or a new build of an unstable island.
    • Exception — Ancora: gatherables on the tutorial island return after 30s (original “fixed quantity, infinite respawn”). Estimated
    • Standing natural resource replenish according to what's left — the next time you touch one, all its yield lines are re-rolled (no partial recovery).
    • Tiles cleared as domain on a tamed island stay empty. Outside the domain it works like any other island.

    Respawn time

    Time = base time × multiplier(remaining share p) Multiplier = clamp(ln[q(1−p) / (p(1−q))] ÷ ln[q(1−0.5) / (0.5(1−q))], 0.25, 3), q = 0.95 Remaining share p = remaining count ÷ (sum of (min+max)/2 over permanent lines)

    We chose logistic growth (the fewer seeds, roots or veins left, the slower the recovery). Leave half and it takes the base time; gather nearly everything and it's slow; gather a little and it's fast. Estimated

    Wood·Rules for bushes falling over

    • Wood (tree in the gathering table name): when the log lines (wood_log, wood_log_*…, Weak Log) run out, the tree disappears even if leaves, branches or fruit remain. This is original behavior. Original (confirmed)
    • Bush (bush_): when the root line runs out, it disappears even if berries, branches or leaves remain. Gathering the roots first loses the rest. Changed from original (developer decision)
    • Trees with no log line to begin with (Bead Tree, Banana, Bamboo, Tea Tree, etc.) disappear only when every line is gathered.

    #Ecology: Growth · Breeding · PlacementLast changed 2026.09.24.5

    Natural resources on an island increase in two ways. Estimated

    • Staged growth: the 11 pairs matched by the original sprite naming rule (X → X_t2) grow from young to mature. Maturing takes twice the regrowth base (grass 2 game days, trees 6 game days) Estimated.
    • Breeding: only plants (tree, grass, bush, cactus, mushroom, flower) spread, into empty tiles within radius 2 of the parent, following the original survival-biome conditions. If the island template's eco_simulation_interval is 0, nothing spreads (tamed islands have a target population of 1, so effectively no spreading).
    • Natural resources don't stand on impassable (mountain, cliff) tiles or on lava — of the 16,744 natural resources in the original's 8 island files, 0 stand on impassable tiles. On water (reeds, mangroves, shoals of fish) they stand as in the original. Original (confirmed)

    #Crater · Dormant CraterLast changed 2026.09.24.5

    A crater has three parts: The crater itself · special resources growing around it · the guardian animal that holds that spot (Namuwiki “Island” §5.2). Each crater type grows one resource of its own around it, and which types appear on which climate and island level is fixed. Estimated

    Active Crater

    • Each island first places Permanent craters first, in table order, then fills the remaining spots from the random list.
    • 3~×5 natural resources of its kind are placed in a ring 2–3 tiles around it (widened once if blocked). Spots where no resource could be placed are discarded.
    • Craters stay at least 7 tiles from each other and from herd spots.
    • Count: 1 per 2,600 land tiles (rounded up), min 1, capped by the template count. Boss islands get 25% of that (rounded up). Of these, the template's open_rate share are open craters and the rest closed craters.

    Dormant craters and Resource Induction Stones

    • Putting a Resource Induction Stone (voucher_resource_induced_stone) into a closed crater (Rift, including the water version) opens it for 600s. Inserting takes 4s in the original.
    • Required count = max(1, int(island level × 0.2)) Original (confirmed)
    • When open, it picks one of the kinds it can summon and warps in 12~×16 of that natural resource within a radius of 3–6 tiles. When time runs out, the warped resources are removed and it closes again. Estimated
    • Types that can be summoned: types marked “Also exists as dormant crater” or “dormant craters only” in the archipelago table; if unmarked, all crater types of that island.
    • An island has at most 16 closed craters, kept 20 tiles from ports, 14 tiles from other craters and 3 tiles around buildings. Estimated
    • Resource Induction Stones have no original source (quests, attendance) here, so on reaching an island you are topped up to twice the required count. Estimated
