    #Building level by material·EffectLast changed 2026.09.27.7

    A building's Expected result and completed level takes the floored average level of all materials selected or placed on the site, clamps it to the blueprint range, and caps it at the Building technique level. Overall character level is not used. If the Building technique level is below the blueprint minimum, both conditions cannot be met and it cannot be built. Estimated

    Building Lv = min(clamp(floor(Σ max(material Lv, 1) / input count), blueprint min_level, blueprint max_level), max(Building technique Lv, 1)) If Building technique Lv < blueprint min_level, it can't be built; with no materials the average is 1; if the blueprint has no max, the cap is skipped

    Building effects are separate from the level average. The material properties of the main slot are averaged if it exists, otherwise those of the blueprint's first slot (rounded, capped). For example, if a Basic Workbench's main material has “High Density” Lv3, it gets durable_incr Lv3 and adds 6 to base max Durability. Materials in other slots count toward building Lv, but their properties are not included in this effect average. Estimated

    A workbench with the rare “Thinly Split” in its main material gets either “More Space” or “Shorter Duration”, based on a seed picked from the item ID. Roof and wall patterns determined by material type are Separate rule. Estimated

    #Sectional BuildingsLast changed 2026.09.24.5

    Modular buildings such as the Hut can have a larger site, and the number of roof, wall and floor material slots grows with size.

    Max per side
    Base 2 slots (original max_modular_size.default_value). Of the technique reward and the crafting proficiency reward (original values 5·6), Largest value is used — they do not stack Original (confirmed)
    Size check
    If resizable + modular, each side ≤ min(blueprint size, limit); if only resizable, ≤ blueprint size; otherwise it must equal the blueprint
    Material count
    Material slot count × size_factor(Roof x * y, Wall 2 * (x + y))rounded Original (confirmed)
    Floor
    Modular buildings are built with 1 floor, and floors are added only via “Add Floor”. The inside of a building with floors is space for furniture and upper floors, so builds can overlap it.
    Co-op island
    Uses the same rule Estimated

    #Building material patternsLast changed 2026.09.24.5

    The Species of the roof/wall material determines the building pattern — Smilodon hide roofs look the same on temperate and tropical islands Changed from original (developer decision).

    • When mixed, the pattern of the most-used material (majority/plurality).
    • If exactly two tie for most, one of the two at random.
    • If three or more tie for the most, it becomes the “Holey Patchwork Roof” — the original bundle lacks that model, so the barracks' default roof is used instead Estimated.
    • Species not in the table get the material's default pattern. Stone is chosen by the rock name in the ore's name (basalt, granite, marble, obsidian) Estimated.

    • Storage comes from armor performance's bag_size and pocket tags (pocket·reform_pocket).
    • Pocket tag: level * 6 (incr)
    • Negative storage does not reduce slots.

    #DomainLast changed 2026.09.24.5

    Declaring a domain on a personal island lets you build inside it under protection. Maximum domain area is set by Pioneer rank (Islands & sailing page, “Pioneer rank”).

    Cell size
    4×4 tiles
    Ground requirement
    At least 8 of a cell's 16 tiles must be ground to claim·Expandable Estimated
    Waterside
    Counts as water when the displayed water depth exceeds 0.4 (the original client's wet-ground threshold) — co-op islands use the same depth calculation Original (confirmed)
    Reset
    Personal island reset once per day
    Return
    Free return to the center of your first domain cell
