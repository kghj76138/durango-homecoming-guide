    Crafting & processing

    Rules and formulas for crafting, processing, modification and repair. The numbers in the tables were obtained by directly running the released game's rule functions (CraftMathRules etc.). Materials, workbenches and times for the 720 recipes are in All recipes.

    Source grade — the badge next to a value shows its basis. Last changed next to a section title is the public version in which that section's content last changed, and links to Patch history.
    • Original (confirmed) A value taken directly from a row of the extracted original data with no signs of editing, or from the original client code — 6 on this page
    • Estimated A value the restoration filled in because the original data has no field for it (e.g. rules that were server-only) — 11 on this page
    • Changed from original (developer decision) A value that exists in the original but was set differently by developer decision — 4 on this page
    • Unverified Values not yet backed by a source — shown in section titles — 2 on this page

    #Overview UnverifiedLast changed 2026.09.24.5

    The crafting window does three things.

    • Crafting (type 0, 625 recipes) — put in materials to make a new item. After a success, a second roll decides Flawless.
    • Processing (type 1, 73 recipes) — changes The material itself, as in tanning, metal treatment, trimming, drying or fermenting. Uses one processing count. Mostly delegated to a workbench.
    • Modification (type 2, 22 recipes) — writes modification-slot tags onto clothing, gloves, shoes, etc. Uses fixed probabilities instead of the stat curve.

    A single craft goes like this: check materials, workbench and tools → determine Result level → compute Requirement from the result level → compare with your Crafting ability to get Success rate·Flawless Rate → Energy and Fatigue cost → work time → result roll → EXP.

    #Crafting abilityLast changed 2026.09.27.6

    Crafting success is decided by the required ability (weapon crafting, clothing crafting, cooking, furniture, construction, sewing, metalworking, handicraft). Single-player and host currently sum each relevant base stat and use the following formula. Estimated

    B = 3 × character level Crafting ability = 35 + floor((B + Σ(relevant base stat − B)) / 6) + gear·title·food·technique bonuses Base constant for the four gathering abilities = 15 (rest of the formula is the same)

    For example, weapon crafting uses Strength and Agility, construction uses Endurance and Intelligence, and metalworking uses Agility, Will and Intelligence. At level 60 with no gear the relevant base stats are 180 each, giving weapon crafting 65 and mining 45. The original server formula does not survive, so the base constant and level curve are a restoration fitted to measurements. Sources for base stats and gear bonuses are in Character stats.

    #Success rate and failureLast changed 2026.09.24.5

    The requirement d is the recipe's required_ability_value formula evaluated at the result level (e.g. 0.5 * level — 20 at level 40). If ability a is at least d, success is guaranteed; if short, the chance drops quadratically. Original (confirmed)

    Success rate = clamp(1 − (max(0, d − a) / 100)², 0, 1)

    On failure, each material rolls for loss separately (loss chance = shortfall/100 Original (confirmed); rolling per material is Estimated). On success or Flawless, all materials are consumed.

    #Result levelLast changed 2026.09.27.10

    Result level is the floored average of material levels, capped by Technique level and clamped to the recipe's min–max level. Changed from original (developer decision)

    Level = clamp(min(floor(sum of material levels / material count), cap), recipe min_level, recipe max_level) Cap = the recipe's technique category level (0 = no technique record → no cap)

    Apart from deciding whether crafting is possible, the workbench level does not limit the result level. Since the recipe range applies last, min_level items still come out even with a low technique.

    #Workload·Energy·Fatigue·EXPLast changed 2026.09.24.5

    The Workload e of one craft is the recipe's effort value; if empty, the level formula is used. e determines Energy, Fatigue and (base) work time. Original (confirmed)

    Base workload e = 5 + (level − 1) × 0.5 Energy = e × 0.7 × (1 + energy cost amplification) × island multiplier Fatigue = 2 × √e × island multiplier Crafting EXP = max(2, 4 + result level)

    Workload and EXP are CraftEffort·CraftExp outputs; Energy and Fatigue are calculated from that e (for recipes that list an effort, that value is e)

    #Work timeLast changed 2026.09.24.5

    Manual work time is the recipe's duration (seconds); if 0, it is e seconds of workload (0 on a delegated recipe means 0s). The restoration's work-time multiplier ×0.5 is then applied. Changed from original (developer decision)

    On top of that, Changed from original (developer decision) stat margin, safe-island and rare attribute reductions apply:

    Time = base × max((1 − total reduction) × (1 − 0.25 × clamp((ability − requirement) / 200, 0, 1)), 0.3) Total reduction = personal/city island crafting reduction (craft_time_reduction_safe) + workbench rare attribute “Shorter Duration” 0.05

    If a cash item's fixed-time modifier (bm_fixed_craft_duration) applies, those seconds are the cap.

    #Processing and smeltingLast changed 2026.09.24.5

    Processing (type 1) changes Material in hand instead of making a new item. Processing count (modifiable_count) must remain, and deduct_modifiable_count processing uses one per run. Flawless-gathered materials get +1 count; materials from gathering mistakes −1.

    • Trimming (trim*) — adds a trimmed-material tag to wood/stone/bone (the original tag is kept).
    • Material Processing (process*) — upgrades trimmed material to processed material.
    • Drying·Smoking·Salting(dry*/smoke*/salt*) — adds dried/dried_leather/smoked and removes “Wet”.
    • Tanning (tan*) — keeps the dried tag and adds tan_leather.
    • Extending (extend_stick/rope/sheet) — moves up the stick/rope/sheet size ladder.
    • Cooking processing (category cook) — removes the raw tags (raw_food, wet).

    #ModificationLast changed 2026.09.24.5

    Modification (tech support, type 2) places One modification slot on clothing, hats, gloves, shoes, bags, weapons and tools and writes tags into it. It uses fixed probabilities regardless of stats — Flawless 5%, success 80%, the rest failure (no critical failure). Original (confirmed)

    • Flawless: every tag at max level.
    • Success: each tag rolls twice between min and max and takes the lower Estimated — low levels are common.
    • A level/max ratio above 0.9 shows “Very rare”, above 0.6 shows “Rare”.
    • On failure the item is unchanged. The modification slot can be overwritten by modifying again.
