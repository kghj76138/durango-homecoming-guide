    Material properties

    Where material properties (latent attributes) and rare attributes come from, what they turn into on crafted items and buildings, and their value per level. The property → effect table is the result of actually running the game's rule functions one property at a time. Crafting rules: Crafting & processing.

    Source grade — the badge next to a value shows its basis. Last changed next to a section title is the public version in which that section's content last changed, and links to Patch history.
    • Original (confirmed) A value taken directly from a row of the extracted original data with no signs of editing, or from the original client code — 3 on this page
    • Estimated A value the restoration filled in because the original data has no field for it (e.g. rules that were server-only) — 17 on this page
    • Changed from original (developer decision) A value that exists in the original but was set differently by developer decision — 3 on this page
    • Unverified Values not yet backed by a source — Shown in section title

    #OverviewLast changed 2026.09.24.5

    Materials (leather, fur, bone, stone, wood, metal, cloth …) carry Property (latent attributes). A property does nothing on the material itself; it turns into Effect tag (Attack up, Defense up, Cold Resistance …) on equipment, tools, clothing and buildings made with that material in a Main material slot. Green-text Rare attribute appear rarely and give special effects (Throw Dirt, Gathering Mania …).

    How properties get attached:

    • Gathering·Butchering roll — each time a material drops, 30% chance of one property (5% of those get two). Estimated
    • Flawless gathering·Failure — flawless adds one more good property + processing count +1; a mistake adds one bad property + processing count −1. Estimated
    • Per species·Fixed properties per tree — fixed ones, such as Oily 8 on Mammoth Pelt. Estimated
    • Processing — raised by repeated tanning, metal treatment and material processing (main +2 · secondary +1 per pass, cap 8).
    • Rare attribute roll — 2%; more likely with the tool's “Secrets of Gathering” and with larger animals. Estimated

    A property's level is at most 8 on one material. A good property and its opposite (Firm ↔ Soft) cancel each other out.

    #Property listLast changed 2026.09.24.5

    #Effects of propertiesLast changed 2026.09.24.5

    The effect on the result when one material with property level 1 goes in the main material slot. Produced by running the game rule functions MaterialTraitRules.Effects and BuildingTraitRules.Effects one property at a time; effect level equals property level (cap 8). “·” means no effect on that part.

    • With several main material slots, Average properties of the materials in the main material slots (rounded) is used. Recipes with a slot named base use that slot, otherwise main.
    • Good and bad sides of the same family combine into a net value (Firm 3 + Soft 1 → Firm 2).
    • Properties don't carry over to food. Repair kits don't inherit material properties either.
    • Intermediate materials (blades, handles, planks, etc.) don't turn properties into effects but carry them over as is — they convert on the final equipment.
    • Firm, elastic and Soft Surface have no effect on gloves, boots or accessories (original description: “However, it has no effect on gloves, boots, or accessories.”).

    #Gathering·Levels from butcheringLast changed 2026.09.24.5

    The level of a property from a gathering/butchering roll is uniform between 1 and the cap. The cap is 1 per 20 item levels (max 3), plus +1 per 3 unstable index on unstable islands (max 8). Estimated

    Cap = min(8, clamp(floor((Item level + 19) / 20), 1, 3) + floor((Unstable index − 1) / 3))

    #Rare attribute (Green)Last changed 2026.09.24.5

    Rare attributes are special properties shown in green text. When a material drops, a 2% chance is rolled and one rare attribute matching that material type is added at level 1. Estimated

    • If the tool has “Secrets of Gathering”, the chance becomes (1 + 1.0) = 2× (latent property rolls too).
    • Butchering applies a multiplier by animal size (table below). Natural resource gathering is ×1. Changed from original (developer decision)
    • On crafted items they become effects only on the part the description names, and which of the two effects applies is decided by the Main material item (preview matches the result). Effect level is 1.
